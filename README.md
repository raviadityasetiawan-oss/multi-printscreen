# Multi PrintScreen (Windhawk Mod)

Mod Windhawk kustom untuk mempercepat proses dokumentasi dan troubleshoot. Nggak perlu lagi ribet copy-paste screenshot satu per satu atau buka menu Win+V secara manual untuk melampirkan banyak gambar ke AI.

Tinggal jepret screenshot beberapa kali berturut-turut, lalu pencet Ctrl+V berulang kali. Hasil screenshot akan keluar bergantian dari yang paling pertama diambil (FIFO).

---

## 🛠️ Cara Install

Sebagai pengguna, kamu nggak perlu ribet salin kode. Cukup ikuti langkah mudah ini:

### 1. Download & Install Windhawk
Jika belum punya aplikasinya, silakan unduh terlebih dahulu:
* Buka situs resmi [windhawk.net](https://windhawk.net).
* Klik tombol **Download** dan instal aplikasi seperti biasa di Windows kamu.

### 2. Cari & Install Mod
* Buka aplikasi **Windhawk** yang sudah terinstal di PC kamu.
* Masuk ke tab **Explore** yang ada di bagian atas.
* Di kolom pencarian, ketik **"Multi PrintScreen"**.
* Setelah mod-nya ketemu, klik tombol **Details**.
* Terakhir, tinggal klik tombol **Accept and Install**.

Sekarang mod sudah aktif dan langsung bisa kamu gunakan tanpa perlu restart!
